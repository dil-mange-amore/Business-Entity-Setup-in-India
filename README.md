Business Entity Setup in India – Interactive Checklist
An interactive web application designed to simplify the process of setting up and managing a business in India.
Features:

Step-by-step checklist for Private Limited, LLP, Sole Proprietorship, IEC, DPIIT recognition, Trademark, Copyright, IT Act compliance, RBI/FEMA, ASCI guidelines, and more.
Three-pane layout:

Overview of requirements (accordion view).
Checklist sections as tabs.
Detailed items with checkboxes and official links to government portals.


Progress tracking:

Dynamic overall progress bar (always visible).
Per-section completion badges.
Local storage persistence + Export/Import options.


Direct links to official portals (MCA, DGFT, Startup India, IP India, RBI, GST, Udyam, ASCI, CERT-In).
Feedback button to email the developer.

Built with HTML, CSS, and vanilla JavaScript for easy hosting on GitHub Pages.
Ideal for entrepreneurs, startups, and compliance teams looking for a structured, actionable guide.
